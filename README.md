# Repo Search

Search public GitHub repositories by keyword. Results are shown ten per page with previous and next navigation. The React and TypeScript app calls GitHub's repository search API directly from the browser and uses plain CSS.

## Run locally

With Node.js 22.12+ on the 22.x line, install dependencies and start Vite.

```sh
npm ci
npm run dev
```

Open the address Vite prints. Press Ctrl+C to stop. Use `npm run build` to type-check and create the static site in `dist/`. Use `npm run preview` to view that build locally.
